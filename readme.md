# Модель сети по продаже электроники  
Django REST API приложение для управления иерархической сетью по продаже электроники с тремя уровнями: завод, розничная сеть и индивидуальный предприниматель.  

## Функциональность  

### Модель данных.  

Иерархическая структура из трех уровней:

 - Завод (уровень 0)
 - Розничная сеть (уровень 1)
 - Индивидуальный предприниматель (уровень 2)

Каждое звено ссылается на одного поставщика.  
Автоматическое определение уровня иерархии  

### Админ-панель

 - Просмотр всех объектов сети
 - Ссылки на поставщиков
 - Фильтрация по городу
 - Admin action для очистки задолженности
 - Поиск по названию и продуктам

### REST API

 - Полный CRUD для узлов сети
 - Запрет на обновление задолженности через API
 - Фильтрация по стране
 - Аутентификация и права доступа

### Технологии

 - Python 3.8+
 - Django 4.2+
 - Django REST Framework
 - PostgreSQL / SQLite
 - django-filter
